# Enterprise Licensing Boundary

Status: deferred.

Dashboard Pi V1 appliance code remains open-source. Future enterprise
controller code may be separately licensable, but no license enforcement is
implemented in V1.

## Boundary Principles

- Keep open appliance protocols documented.
- Keep enterprise server code separate from the GPLv2 appliance integration.
- Do not add commercial-only runtime checks to the V1 appliance.
- Do not make the appliance unusable without a controller license.
- Keep any future edition/feature-gate model in deferred docs until the
  enterprise product exists.
